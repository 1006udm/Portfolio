# Unnati Maharjan — Portfolio

A retro platformer portfolio. Play the level, or open the menu (top bar) for About, Status, Skills, Equip and Contact.

Live: https://1006udm.github.io/Portfolio/

- `index.html` — page
- `css/style.css`, `js/script.js` (menu, viewer), `js/game.js` (platformer)
- `assets/` — images; game sprites by Kenney (CC0, see `assets/game/KENNEY-LICENSE.txt`)

Deployed automatically by GitHub Pages via `.github/workflows/static.yml` on every push to `main`.
